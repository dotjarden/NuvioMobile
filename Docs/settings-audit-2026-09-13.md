# Settings audit — September 13, 2026

Scope: every control in the seven tvOS settings categories, including conditional controls and local diagnostics. Inspected the view binding, persistence/repository action, and consuming screen/engine. This is a wiring audit plus targeted runtime checks, not certification of external service accounts or every video format.

## Validation

- NativeSubtitleStyleTests: applies saved colors, opacity, bold, scale and outline to an actual AVPlayerItem; changing preferences replaces prior rules; actionable errors are preserved while transport dumps are shortened. All three tests passed.
- Remote UI checks: category switching; expand/collapse; buffer menu persistence across relaunch and restoration; audio menu; inline plugin input/action; Library & Sync placement; collapsed diagnostics; Add-ons push/back. All four targeted settings UI checks passed; the final buffer/language and inline-input pass completed on the tvOS 27 simulator. The invalid-URL submission check also passed for the actual Install action and retained URL; final recheck includes concise error feedback.
- No account disconnections, key removal, provider removal, watch-history edits or live OAuth approvals are used as test probes.
- Device build passed and the final update was installed on the paired Apple TV with app data preserved. The device was asleep, so foreground launch was unavailable.
- No shared Kotlin persistence schema changes. Existing account/profile synchronization remains in the shared repositories. Device-specific options remain device-local.

Apple API references used for the native caption fix: [AVTextStyleRule](https://developer.apple.com/documentation/avfoundation/avtextstylerule) and [preferredForwardBufferDuration](https://developer.apple.com/documentation/avfoundation/avplayeritem/preferredforwardbufferduration). Runtime colors use the SDK's documented ARGB component ordering.
